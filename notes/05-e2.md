## E2-freetext: how to phrase free-text answers ($0.029)
Variants (prompt rule for fields typed freetext by stage 0), 4 single-entry docs, everything else cached:
- **describe** (current): the field's description decides the phrasing.
- **verbatim**: copy the shortest passage that states the term, word for word.
- **concise**: answer in the length and format of the description's example, in the document's words, keeping every fact.

Scored strictly (`tools/validate.py`) and with a judge from another model family (claude-haiku-5.5; 47 distinct pairs,
2 calls, $0.0016). Spot check: the judge is too lenient on short identifier fields (accepted "Second Floor, West
Section, Suite 214W" for "Suite 214W"), so the realistic judged score applies the judge only to fields typed freetext,
matching the brief ("slightly more lenient on free-text fields").

Differences are near the ±0.03 noise on 4 documents. **concise** is best under strict scoring and within 0.014 of the

## Pointer mode (user's template idea applied to single-entry documents) — $0.058

**Design.** Field handling decided from type + description only: *pointer* (numbers, dates, percentages, names, codes:
value + exact quote; code locates the quote, verifies or parses the value, sets citation + page from the found span),
*quote* (free text whose description says "as the lease states it"/"as written"/"verbatim": the exact document span is
the answer), *summary* (other free text, concise rule), *value* (booleans, lists, computed). Spreadsheet single-entry
lists: the pointer is a cell address and code reads the exact cell. Unfound quotes never invent or delete a value
(model value kept, lower confidence). `EXTRACT_STYLE=pointer`; default stays `value`.

| Approach | Strict | Judged (freetext) | Pages present / correct (lease_001, lease_003, om_001) | $ / doc |
|---|---|---|---|---|
| value (current) | 0.879 | 0.935 | 24/22, 36/36, 24/20 | ~0.0035 |
| pointer | 0.879 | 0.935 | **31/28**, 36/31, 24/**22** | ~0.0039 |

Accuracy is identical; pointer adds verifiable quotes and more correct pages on the scanned lease and the OM, but
picked a different (non-answer) occurrence on lease_003 five times. Quote-style answers come out as whole sentences
("Tenant shall use and occupy the Premises for general office purposes…") where the answers are fragments
("general office purposes"): strict misses, judged hits.
